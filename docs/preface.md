# はじめに

「さっき見ていた商品の広告が、まったく別のサイトに出てきた」。多くの人が経験しているこの現象の裏側では、ページが表示されるまでの約 0.1 秒の間に、広告枠をめぐるオークションが行われています。この仕組みが **RTB（Real-Time Bidding、リアルタイム入札）** です。

RTB はデジタル広告の中核をなす技術でありながら、登場するプレイヤーが多く、専門用語も英語の略語ばかりで、全体像をつかみにくい分野です。本書は、RTB を初めて学ぶ人が、**全体像 → 仕組み → 戦略 → 周辺の課題**の順に、無理なく理解できることを目指して書きました。

## 対象読者

- デジタル広告の業界に入ったばかりの人（エンジニア、営業、企画、マーケティング担当など）
- アドテクノロジーの研究や開発に関心のある学生
- 「なぜ見たばかりの商品の広告が出てくるのか」を仕組みから理解したい人

## 前提知識

Web ページがサーバーから送られてくる HTML で作られていること、Cookie がブラウザに保存される小さなデータであること、程度の知識があれば読み進められます。第3章の JSON や第5章の数式は、読み飛ばしても全体の理解には支障がありません。

## 本書の構成

| 部 | 章 | 学ぶこと |
|----|----|---------|
| 基礎 | 第1〜3章 | 登場するプレイヤー、RTB の処理の流れ、データ形式（OpenRTB） |
| 仕組みと戦略 | 第4〜6章 | オークションのルール、DSP の入札戦略、取引形態 |
| 周辺の課題 | 第7〜9章 | プライバシー、透明性と不正対策、指標 |

各章は「この章で学ぶこと」で始まり、「この章のまとめ」で終わります。巻末の[用語集](glossary.md)と[確認問題](quiz.md)は、復習や辞書代わりに活用してください。
