# 用語集

## あ行〜わ行

| 用語 | 説明 | 関連章 |
|-----|------|-------|
| **アドエクスチェンジ** | 広告枠の売り手と買い手が取引する市場。オークションを行う | [1](01-overview.md) |
| **アドサーバー** | どの広告を表示するかを最終決定・配信するシステム | [1](01-overview.md) |
| **アドフラウド** | ボットなどによる不正な表示・クリックで広告費をだまし取る行為 | [8](08-quality-fraud.md) |
| **インプレッション** | 広告が1回表示されること | [1](01-overview.md) |
| **ウォーターフォール** | SSP に優先順位をつけて順番に問い合わせる古い方式 | [4](04-auction.md) |
| **クッキーシンク** | SSP と DSP の Cookie ID を対応づける仕組み | [7](07-privacy.md) |
| **コンテキスト広告** | ページの内容に合わせて広告を出す手法。個人を追跡しない | [7](07-privacy.md) |
| **セカンドプライスオークション** | 勝者が「2位の入札額 + 最小単位」を支払う方式 | [4](04-auction.md) |
| **ディール ID** | PMP や優先取引などの特別な取引を識別する ID | [6](06-deals.md) |
| **ビッドシェーディング** | ファーストプライスで払いすぎないよう、入札額を下げる技術 | [4](04-auction.md) |
| **ビューアビリティ** | 広告が実際にユーザーに見える状態で表示されたかどうか | [8](08-quality-fraud.md) |
| **ファーストプライスオークション** | 勝者が自分の入札額をそのまま支払う方式。現在の主流 | [4](04-auction.md) |
| **フリークエンシーキャップ** | 同じユーザーに広告を出す回数の上限 | [5](05-dsp-bidding.md) |
| **フロアプライス** | 媒体社が設定する最低落札価格 | [4](04-auction.md) |
| **ブランドセーフティ** | 不適切なページに広告が出ないようにすること | [8](08-quality-fraud.md) |
| **ヘッダービディング** | 複数の SSP に同時に入札を募る方式 | [4](04-auction.md) |
| **ペーシング** | 予算を期間中に適切なペースで消化する調整 | [5](05-dsp-bidding.md) |
| **リターゲティング** | 過去に自社サイトを訪れた人に広告を出す手法 | [7](07-privacy.md) |

## アルファベット

| 用語 | 正式名称 | 説明 | 関連章 |
|-----|---------|------|-------|
| **ads.txt** | Authorized Digital Sellers | 媒体社が正規の販売者を公開するファイル | [8](08-quality-fraud.md) |
| **ATT** | App Tracking Transparency | iOS でアプリが IDFA を使うときに許可を求める仕組み | [7](07-privacy.md) |
| **CMP** | Consent Management Platform | 同意バナーを表示し、同意情報を管理する仕組み | [7](07-privacy.md) |
| **CPA** | Cost Per Acquisition | 1 コンバージョンあたりのコスト | [9](09-metrics.md) |
| **CPC** | Cost Per Click | 1 クリックあたりのコスト | [9](09-metrics.md) |
| **CPM** | Cost Per Mille | 1,000 回表示あたりのコスト | [9](09-metrics.md) |
| **CTR** | Click Through Rate | クリック率 | [9](09-metrics.md) |
| **CTV** | Connected TV | インターネットに接続したテレビ。動画広告の成長分野 | [3](03-openrtb.md) |
| **CVR** | Conversion Rate | コンバージョン率 | [9](09-metrics.md) |
| **DMP / CDP** | Data Management Platform / Customer Data Platform | ユーザーデータを管理・活用する基盤 | [1](01-overview.md) |
| **DSP** | Demand-Side Platform | 広告主側の入札システム | [1](01-overview.md) |
| **eCPM** | effective CPM | 実質的な 1,000 表示あたり収益 | [9](09-metrics.md) |
| **GDPR** | General Data Protection Regulation | EU の個人データ保護規則 | [7](07-privacy.md) |
| **GPP** | Global Privacy Platform | 複数地域の同意情報を扱う IAB Tech Lab の仕様 | [7](07-privacy.md) |
| **IDFA / GAID** | Identifier for Advertisers / Google Advertising ID | iOS / Android の広告 ID | [7](07-privacy.md) |
| **MRC** | Media Rating Council | 広告計測の基準を定める米国の団体 | [8](08-quality-fraud.md) |
| **OpenRTB** | — | IAB Tech Lab が策定する RTB の標準プロトコル | [3](03-openrtb.md) |
| **PG** | Programmatic Guaranteed | 在庫と価格を保証するプログラマティック取引 | [6](06-deals.md) |
| **PMP** | Private Marketplace | 招待された買い手だけが参加できるオークション | [6](06-deals.md) |
| **QPS** | Queries Per Second | 1 秒あたりのリクエスト数 | [9](09-metrics.md) |
| **ROAS** | Return On Ad Spend | 広告費に対する売上の割合 | [9](09-metrics.md) |
| **RTB** | Real-Time Bidding | インプレッションごとにリアルタイムで行われるオークション | [2](02-rtb-flow.md) |
| **schain** | SupplyChain Object | 広告枠の販売経路を記録した Bid Request 内の情報 | [8](08-quality-fraud.md) |
| **sellers.json** | — | SSP が自社のアカウントと販売者の対応を公開するファイル | [8](08-quality-fraud.md) |
| **SPO** | Supply Path Optimization | 効率の良い販売経路だけを選んで買う取り組み | [8](08-quality-fraud.md) |
| **SSP** | Supply-Side Platform | 媒体社側の販売システム | [1](01-overview.md) |
| **tmax** | — | Bid Request の応答期限（ミリ秒） | [3](03-openrtb.md) |
| **VAST** | Video Ad Serving Template | 動画広告を配信するための XML 形式 | [3](03-openrtb.md) |
